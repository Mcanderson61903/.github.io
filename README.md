# VS Code HTML Starter (macOS)

This is a modern starter project for HTML/CSS/JS that looks great out of the box and plays perfectly with Visual Studio Code on macOS.

## Quick Start

1. **Install VS Code** (Mac): download from the official site and drag to Applications.
2. **Recommended extensions**:
   - Live Server (ritwickdey.LiveServer) – local preview with auto‑reload.
   - Prettier (esbenp.prettier-vscode) – opinionated code formatter.
3. Open this folder in VS Code (**File → Open Folder…**).
4. Install the recommended extensions if prompted.
5. Right‑click `index.html` → **Open with Live Server**.
6. Edit HTML/CSS. Changes appear instantly in the browser.

## Useful VS Code Tips

- Press `Cmd+Shift+P` and type **Preferences: Open Settings (JSON)** to tweak settings.
- Use Emmet: typing `ul>li*3` and pressing `Tab` expands to a list with 3 items.
- Format on save: enabled in `.vscode/settings.json`.

## Deploy

- **GitHub Pages**: push to a repo and enable Pages on the `main` branch (root). Your site will be live at `https://<user>.github.io/<repo>`.

Enjoy!
